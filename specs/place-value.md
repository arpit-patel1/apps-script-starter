# Place value practice

Ported from `network-element-ai` place-value drills (prompt + typed answer). Grades **3–5**.

## Types

| Type | Label | Kid does |
| --- | --- | --- |
| `digit_value` | Digit value | Value of a highlighted digit in a number |
| `standard` | Standard form | Expanded form → digits |
| `expanded` | Expanded form | Number → `3000 + 200 + 5` (order flexible) |
| `word` | From words | Word form → digits |
| `compare` | Compare | Write `<`, `>`, or `=` |

## Notes

- Chart fill-in UI and place-value add/subtract modes are deferred (we already have Addition/Subtraction activities).
- Expanded answers normalize commas/spaces and accept terms in any order.
